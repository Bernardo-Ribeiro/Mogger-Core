# Logo Mogger Core

## Arquivos oficiais

- [`mogger-core.svg`](mogger-core.svg): logotipo vetorial principal, com fundo transparente. Use em impressão, adesivos e materiais que aceitem SVG.
- [`mogger-core-glass.png`](mogger-core-glass.png): versão PNG transparente com acabamento de vidro inspirado no Frutiger Aero e cursor de mouse. Use em apresentações e peças digitais.

## Cores

- Carvão: `#171A1D`
- Verde neon: `#A6FF00`

O SVG é o arquivo preferido para ampliar e produzir materiais impressos. O PNG tem 1672 × 941 px e canal alfa.
