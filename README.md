# Mogger Core

Repositório da equipe **Mogger Core**, participante da competição de construção de carrinhos com Arduino.

Este espaço reúne a identidade visual, os documentos da equipe e os arquivos de projeto do carrinho. Os diretórios de projeto estão preparados para receber os esquemas e demais materiais à medida que forem desenvolvidos.

## Estrutura

```text
logo/                    Logotipos oficiais
identidade/mascote/      Conceito e arquivos do mascote
docs/equipe/             Informações e organização da equipe
carrinho/esquemas/       Diagramas elétricos e ligações
carrinho/mecanica/       Chassi, medidas e montagem
carrinho/eletronica/     Componentes e circuitos
carrinho/firmware/       Código e documentação do Arduino
```

## Identidade visual

O logo vetorial e a versão PNG com efeito de vidro Aero e fundo transparente estão em [`logo/`](logo/). Consulte [`logo/README.md`](logo/README.md) para formatos e cores.

## Carrinho

Os diretórios em `carrinho/` contêm instruções para adicionar diagramas, arquivos de montagem, lista de componentes e firmware. Inclua medidas e versões nos documentos para que as alterações do projeto fiquem claras para toda a equipe.

## Equipe

Informações gerais e espaço para registrar integrantes e funções estão em [`docs/equipe/`](docs/equipe/).
